1 Option A: Zero-Config System Domain

No DNS configuration required! Use the default System Domain option when creating links for instant 0-setup shortening.

URL Format: https://links.orfa.dev/your-slug
2 Option B: Custom Subdomain (e.g. go.orfa.dev)

Add 1 simple CNAME record in your Cloudflare / DNS provider targeting your main application domain.

Type: CNAME
Name / Host: go (or * for wildcard)
Target: links.orfa.dev
Cloudflare Proxy: Orange Cloud (Proxied)
3 Option C: External Domain (link.customer.com)

For third-party customers connecting their external domain, add 1 CNAME pointing to your server.

Type: CNAME
Host: link
Target: links.orfa.dev
Status: Auto-verified upon click
💡 Pro Tip: Once your CNAME record is added, click "Verify DNS Now" in the list below to immediately activate your domain!
