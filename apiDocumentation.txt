# Link Shortener API Documentation

Base API URL: `https://api.orfa.dev/api/v1` (or local `http://localhost:3000/api/v1`)
Database Target: `db.orfa.dev`
Authentication: Bearer Token (JWT) or API Key (`Authorization: Bearer sl_live_...`)

## 1. Authentication Endpoints

### Register User
`POST /api/v1/auth/register`

**Request Body:**
```json
{
  "email": "user@example.com",
  "password": "SecurePassword123!"
}
```

**Response (201 Created):**
```json
{
  "user": {
    "id": "usr_9a8b7c6d",
    "email": "user@example.com",
    "status": "active",
    "created_at": "2026-07-27T11:00:00Z"
  },
  "tokens": {
    "access_token": "eyJhbGciOi...",
    "refresh_token": "eyJhbGciOi..."
  }
}
```

`POST /api/v1/auth/login`

**Request Body:**
```json
{

}
```

**Response (200 OK):**
```json
{
```

`POST /api/v1/auth/logout`

## 2. Domain Management Endpoints

Headers required: `Authorization: Bearer <access_token>` or `Authorization: Bearer <api_key>`

### Add Domain
`POST /api/v1/domains`

**Request Body:**
```json
{
  "hostname": "go.orfa.dev"
}
```

**Response (201 Created):**
```json
{
  "id": "dom_123456",
  "hostname": "go.orfa.dev",
  "status": "pending",
  "ssl_status": "pending",
  "dns_records": [
    {
      "type": "CNAME",
      "name": "go",
      "value": "domains.shortlink-service.com"
    },
    {
      "type": "TXT",
      "name": "_shortlink-verification.go",
      "value": "shortlink-verification=4f8d92a1c0"
    }
  ],
  "created_at": "2026-07-27T11:05:00Z"
}
```

### List Domains
`GET /api/v1/domains`

**Response (200 OK):**
```json
[
  {
    "id": "dom_123456",
    "hostname": "go.orfa.dev",
    "status": "active",
    "ssl_status": "active",
    "created_at": "2026-07-27T11:05:00Z"
  }
]
```

### Get Domain Details
`GET /api/v1/domains/:id`

### Verify Domain DNS
`POST /api/v1/domains/:id/verify`

**Response (200 OK):**
```json
{
  "id": "dom_123456",
  "hostname": "go.orfa.dev",
  "status": "active",
  "verification_message": "TXT record successfully verified."
}
```

### Delete Domain
`DELETE /api/v1/domains/:id`

## 3. Short Link Management Endpoints

### Create Short Link
`POST /api/v1/links`

**Request Body:**
```json
{
  "domain_id": "dom_123456",
  "destination_url": "https://example.com/long/path/address",
  "custom_slug": "github",
  "redirect_type": 302,
  "expires_at": null,
  "password": null
}
```

**Response (201 Created):**
```json
{
  "id": "lnk_987654",
  "short_url": "https://go.orfa.dev/github",
  "destination_url": "https://example.com/long/path/address",
  "domain_id": "dom_123456",
  "slug": "github",
  "redirect_type": 302,
  "is_active": true,
  "expires_at": null,
  "created_at": "2026-07-27T11:10:00Z"
}
```

### List Short Links
`GET /api/v1/links?domain_id=dom_123456`

### Get Link Details
`GET /api/v1/links/:id`

### Update Short Link
`PATCH /api/v1/links/:id`

**Request Body:**
```json
{
  "destination_url": "https://new-url.com",
  "is_active": false,
  "redirect_type": 301
}
```

### Delete Short Link
`DELETE /api/v1/links/:id`

## 6. Redirect Engine

When a visitor requests `https://<hostname>/<slug>`:

1. Host Header (`Host: go.orfa.dev`) and URL path (`/github`) are extracted.
2. Fast lookup in Cache (Redis/In-memory) for `redirect:go.orfa.dev:github`.
3. If cache miss, database query to PostgreSQL at `db.orfa.dev`:
   ```sql
   SELECT destination_url, redirect_type, is_active, expires_at 
   FROM short_links 
   JOIN domains ON short_links.domain_id = domains.id
   WHERE domains.hostname = $1 AND short_links.slug = $2;
   ```
4. If found & active & not expired:
   - Cache result with TTL (e.g. 3600s).
   - Enqueue async click log (`click_events` table).
   - Yönlendirme: Return HTTP `301` or `302` response with `Location: <destination_url>`.
5. If link invalid or missing: Return HTTP `404 Not Found`.

## 7. Database Schema Reference

Connecting to host: `db.orfa.dev`

```sql
CREATE TABLE users (
    id VARCHAR(36) PRIMARY KEY,
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    status VARCHAR(50) DEFAULT 'active',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE domains (
    id VARCHAR(36) PRIMARY KEY,
    user_id VARCHAR(36) REFERENCES users(id) ON DELETE CASCADE,
    hostname VARCHAR(255) UNIQUE NOT NULL,
    verification_token VARCHAR(255) NOT NULL,
    verification_status VARCHAR(50) DEFAULT 'pending', -- pending, verified, active
    ssl_status VARCHAR(50) DEFAULT 'pending',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE short_links (
    id VARCHAR(36) PRIMARY KEY,
    user_id VARCHAR(36) REFERENCES users(id) ON DELETE CASCADE,
    domain_id VARCHAR(36) REFERENCES domains(id) ON DELETE CASCADE,
    slug VARCHAR(100) NOT NULL,
    destination_url TEXT NOT NULL,
    redirect_type INT DEFAULT 302, -- 301 or 302
    is_active BOOLEAN DEFAULT TRUE,
    expires_at TIMESTAMP WITH TIME ZONE NULL,
    password_hash VARCHAR(255) NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT unique_domain_slug UNIQUE (domain_id, slug)
);

CREATE TABLE click_events (
    id VARCHAR(36) PRIMARY KEY,
    short_link_id VARCHAR(36) REFERENCES short_links(id) ON DELETE CASCADE,
    clicked_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    country VARCHAR(10),
    device_type VARCHAR(50),
    browser VARCHAR(50),
    operating_system VARCHAR(50),
    referrer TEXT,
    ip_hash VARCHAR(64)
);

CREATE TABLE api_keys (
    id VARCHAR(36) PRIMARY KEY,
    user_id VARCHAR(36) REFERENCES users(id) ON DELETE CASCADE,
    name VARCHAR(255) NOT NULL,
    key_hash VARCHAR(255) NOT NULL,
    last_used_at TIMESTAMP WITH TIME ZONE NULL,
    expires_at TIMESTAMP WITH TIME ZONE NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
```

## 8. DNS & SSL Setup Guide

### Customer DNS Setup
1. **CNAME Record**:
   - Type: `CNAME`
   - Name: `go` (or `@` for root domain)
   - Target: `domains.shortlink-service.com`
2. **TXT Ownership Record**:
   - Type: `TXT`
   - Name: `_shortlink-verification.go`
   - Value: `shortlink-verification=<verification_token>`

### Reverse Proxy & SSL (Traefik / Let's Encrypt)
- Dynamic route creation forwards incoming host requests to the Redirect Service.
- Traefik automatically requests Let's Encrypt SSL certificate once CNAME resolves to the server IP.
